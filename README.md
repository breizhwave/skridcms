# Skrid

*Skrid* means "writing" in Breton. It is a small CMS that edits a static website's own `.html` files in place:
log in, click a text on the real page, type, save. The change is written into the file itself and nothing
else in it moves (indentation, comments, scripts and attributes stay byte for byte as they were).

No database, no build, no template: the site stays your site.

- More, with screenshots: **https://wave.bzh/en/breizhvibe/skridcms/**
- Code: **https://github.com/breizhwave/skridcms**

## Requirements

- PHP **8.1** or newer, with the `dom` and `mbstring` extensions (standard on almost every shared host).
- A site made of plain `.html` pages (`.php` pages also work: their fixed texts are editable, their code never changes).
- PHP must be able to write the site's `.html` files and `skrid/data/`.
- On Apache, the `.htaccess` files close `data/` and `lib/` to visitors. On another server, deny those two folders yourself.
- Pages in UTF-8.

## Install

1. Upload this **`skrid/`** folder to the root of the website, next to `index.html`.
2. Open **`https://your-site/skrid/`** and log in. The password is **`KL`** for now:
   change it in *Admin › Settings* before the site goes public.
3. Optional: show the **edit pen** on the site's pages, for you only. Add before `</body>`:

   ```html
   <script src="/skrid/assets/pen.js" defer></script>
   ```

   Visitors see nothing. Once you have logged in, a pen sits at the bottom left of every page and opens it in Skrid.
   On 127.0.0.1 it stays after the login has expired, and online it lasts until you log out or close the browser.

Settings that rarely need changing (site folder, excluded folders, copies kept per page, editor language)
are in `config.php`.

Try it on your computer:

```sh
cp -R skrid /path/to/my-site/
php -S 127.0.0.1:8000 -t /path/to/my-site
# then open http://127.0.0.1:8000/skrid/   (password KL)
```

## What you get

- **Edit texts on the page**: headings, paragraphs, list items, captions, table cells. Bold, italic, links.
- **Blocks**: select a section, card or paragraph, then move it, duplicate it, delete it or drag it elsewhere, and edit its classes.
- **Admin**: every page with its title and description (Google preview, `og:` copies follow), history of
  each page with one-click restore, activity log, a form editor for the site's JSON files, settings.
- A copy of the page before every save (30 kept per page, in `skrid/data/backups/`).
- Editor in French or English.

## Good to know

- A site **generated by a build** overwrites its HTML at the next build. Use Skrid on sites whose HTML
  *is* the source, or edit the source.
- The site header and footer are not editable yet (they repeat on every page of a language).
